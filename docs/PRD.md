## 1. 제품 개요

ValueForge는 KOSPI·KOSDAQ 전 종목을 대상으로 매일 자동으로 데이터를 수집하고, 4단계 가치투자 스크리닝 파이프라인을 실행하여 순위가 매겨진 투자 후보를 웹 대시보드로 제공하는 플랫폼이다.

전체 시스템은 무료 또는 최소 비용 인프라 위에서 동작하며, 1인 개발자가 유지보수 가능하도록 설계되었다.

---

## 2. 문제 정의

가치투자에 관심 있는 한국 개인투자자는 KOSPI·KOSDAQ의 약 2,500개 이상 종목을 재무 지표로 스크리닝할 수 있는 무료 자동화 도구가 없다. 수동 스크리닝은 다음의 문제를 수반한다:

- KRX·DART에서 데이터를 매일 수동 다운로드
- 자체 스프레드시트 모델 구축 및 유지
- 매 거래일마다 계산 반복
- 저평가 종목과 가치 함정(value trap)의 구별이 어려움

ValueForge는 이 전 과정을 자동화하여 진입 장벽을 낮춘다.

## 5. 사용자 페르소나

### 페르소나 A — DIY 가치투자자 (주 타겟)

- 기본적인 재무 지식을 갖춘 개인투자자
- 2,500개 종목 전체를 직접 분석하기 어려움
- PER·PBR·ROE 개념은 이해하지만 자동화 도구 부재
- 대시보드로 후보군을 추려 직접 추가 분석 수행
- 주 2-3회 방문, CSV 내보내기 활용

### 페르소나 B — 퀀트 스크리너 (보조 타겟)

- 자체 스크리닝 로직을 보유한 중급 이상 투자자
- ValueForge 랭킹과 자신의 결과를 교차 검증
- SQLite 파일 직접 다운로드하여 커스텀 쿼리 수행
- 스코어 산출 방법론의 투명성에 관심

## 8. 기술 제약사항

- SQLite가 유일한 데이터베이스 — 서버형 DB 불가
- Cloudflare R2가 유일한 스토리지 레이어
- 무거운 연산은 Streamlit Cloud에서 절대 실행 불가
- 분석 서버는 에페머럴(일시적)로 실행 후 종료
- 모든 자격증명은 환경 변수/시크릿으로 관리 — 코드·커밋에 포함 불가
- Python 3.11 이상

## 9. 인프라 설계

```
Hetzner CX11 VPS ($3.29/월) 또는 GitHub Actions (무료)
  └── Python 파이프라인
        ├── pykrx → 주가 데이터
        ├── DART OpenAPI → 재무 데이터
        ├── 스크리닝 파이프라인 → SQLite
        └── boto3 → Cloudflare R2 업로드

Cloudflare R2 (무료 티어)
  ├── latest.db            ← 항상 최신
  ├── latest_metadata.json
  └── history/YYYY-MM-DD.db  ← 7일 롤링

Streamlit Cloud (무료 티어)
  └── latest.db R2에서 다운로드 (30분 캐시)
      └── 사전 연산된 데이터만 렌더링
```

→ 상세 아키텍처: [ARCHITECTURE.md](ARCHITECTURE.md)

## 10. 데이터 흐름

```
[KOSPI·KOSDAQ 장 마감 15:30 KST]
         │  ~1시간 데이터 전파 대기
         ▼
[파이프라인 실행 17:00 KST]
         │
         ├─► pykrx → 전 종목 코드 + 주가 데이터
         ├─► DART OpenAPI → 3개년 재무 데이터
         ├─► SQLite 작성 (stocks, prices, fundamentals)
         ├─► Stage 1 필터 → ~300-700개 후보
         ├─► Stage 2 스코어링 → 복합 점수
         ├─► Stage 3 함정 감지 → 위험 종목 플래그
         ├─► Stage 4 랭킹 → 최종 순위
         ├─► R2 업로드: latest.db + history/YYYY-MM-DD.db
         ├─► 7일 이상 백업 삭제
         └─► latest_metadata.json 갱신

[사용자 대시보드 접속]
         │
         ├─► 캐시 확인 (30분 TTL)
         ├─► 만료 시: R2에서 latest.db 다운로드
         └─► SQLite 쿼리 → UI 렌더링
```

## 13. MVP 범위

**포함**

- KOSPI·KOSDAQ 전 종목 대상 일일 스크리닝
- 4단계 필터링 파이프라인
- 5차원 스코어링 (가치, 품질, 안전성, 성장성, 모멘텀)
- 가치 함정 감지 및 플래그
- 상위 50개 후보 랭킹 대시보드
- 종목 상세 점수 분해 뷰
- 시장·섹터·점수 기준 필터링
- SQLite 생성 및 R2 업로드
- GitHub Actions 또는 VPS 자동화
- 데이터 최신성 지표

**제외** → [비목표](#4-비목표-mvp-제외) 참조

**V1.1 완성된 기능**

- ✅ 정확한 섹터/업종 분류 (DART 표준산업분류 적용)
- ✅ 점수 추세 지표 (20일 변화율, 변동성)
- ✅ 현금흐름 품질 필터 (FCF/순이익 비율 < 0.3)
- ✅ PEG 비율 필터 (PER/성장률 > 2.0)
- ✅ 배당금 추세 필터 (2년 연속 감소)
- ✅ 공시 신선도 경고 (60일 이상 지연)
- ✅ 기업 지배구조 리스크 (최대주주 지분율 50% 이상)
- ✅ Gemini AI 기반 종합 투자 분석 및 조언 (상위 20개 종목)

**MVP 이후 (V2)**

- 섹터 상대 스코어링
- 점수 추세 차트 (Streamlit 대시보드)
- 파워 유저용 SQLite 다운로드
- 기관 보유율 추이 차트
- 임원진 변화 추적
