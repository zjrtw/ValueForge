## 1. 제품 개요

ValueForge는 KOSPI·KOSDAQ 전 종목을 대상으로 매일 자동으로 데이터를 수집하고, 4단계 가치투자 스크리닝 파이프라인을 실행하여 순위가 매겨진 투자 후보를 웹 대시보드로 제공하는 플랫폼이다.

전체 시스템은 무료 또는 최소 비용 인프라 위에서 동작하며, 1인 개발자가 유지보수 가능하도록 설계되었다.

---

## 2. 문제 정의

가치투자에 관심 있는 한국 개인투자자는 KOSPI·KOSDAQ의 약 2,500개 이상 종목을 재무 지표로 스크리닝할 수 있는 무료 자동화 도구가 없다. 수동 스크리닝은 다음의 문제를 수반한다:

- KRX·DART에서 데이터를 매일 수동 다운로드
- 자체 스프레드시트 모델 구축 및 유지
- 매 거래일마다 계산 반복
- 저평가 종목과 가치 함정(value trap)의 구별이 어려움

ValueForge는 이 전 과정을 자동화하여 진입 장벽을 낮춘다.

## 5. 사용자 페르소나

### 페르소나 A — DIY 가치투자자 (주 타겟)

- 기본적인 재무 지식을 갖춘 개인투자자
- 2,500개 종목 전체를 직접 분석하기 어려움
- PER·PBR·ROE 개념은 이해하지만 자동화 도구 부재
- 대시보드로 후보군을 추려 직접 추가 분석 수행
- 주 2-3회 방문, CSV 내보내기 활용

### 페르소나 B — 퀀트 스크리너 (보조 타겟)

- 자체 스크리닝 로직을 보유한 중급 이상 투자자
- ValueForge 랭킹과 자신의 결과를 교차 검증
- SQLite 파일 직접 다운로드하여 커스텀 쿼리 수행
- 스코어 산출 방법론의 투명성에 관심

## 8. 기술 제약사항

- SQLite가 유일한 데이터베이스 — 서버형 DB 불가
- Cloudflare R2가 유일한 스토리지 레이어
- 무거운 연산은 Streamlit Cloud에서 절대 실행 불가
- 분석 서버는 에페머럴(일시적)로 실행 후 종료
- 모든 자격증명은 환경 변수/시크릿으로 관리 — 코드·커밋에 포함 불가
- Python 3.11 이상

## 9. 인프라 설계

```
Hetzner CX11 VPS ($3.29/월) 또는 GitHub Actions (무료)
  └── Python 파이프라인
        ├── KRX Open API → 주가 데이터
        ├── DART OpenAPI → 재무 데이터
        ├── 스크리닝 파이프라인 → SQLite
        ├── [V2] 네이버/다음 금융 뉴스 수집기
        ├── [V2] Gemini API (Free Tier) → AI 정성 분석
        └── boto3 → Cloudflare R2 업로드

Cloudflare R2 (무료 티어)
  ├── latest.db            ← 항상 최신 (AI 분석 결과 포함)
  ├── latest_metadata.json
  └── history/YYYY-MM-DD.db  ← 7일 롤링

Streamlit Cloud (무료 티어)
  └── latest.db R2에서 다운로드 (30분 캐시)
      └── 사전 연산된 데이터만 렌더링 (AI 가이드 포함)

[V2] Google Gemini API (무료 티어)
  └── Flash 모델: 1,500 요청/일 무료
      └── 90건 분석 ≈ 일일 한도의 6% 사용
```

→ 상세 아키텍처: [ARCHITECTURE.md](ARCHITECTURE.md)

## 10. 데이터 흐름

```
[KOSPI·KOSDAQ 장 마감 15:30 KST]
         │  ~1시간 데이터 전파 대기
         ▼
[파이프라인 실행 17:00 KST]
         │
         ├─► KRX Open API → 전 종목 코드 + 주가 데이터
         ├─► DART OpenAPI → 3개년 재무 데이터
         ├─► SQLite 작성 (stocks, prices, fundamentals)
         ├─► Stage 1 필터 → ~300-700개 후보
         ├─► Stage 2 스코어링 → 복합 점수
         ├─► Stage 3 함정 감지 → 위험 종목 플래그
         ├─► Stage 4 랭킹 → 최종 순위
         ├─► [V2] Stage 5 AI 분석 → 상위 N개 종목 정성 가이드 생성
         │        ├─► 뉴스 수집 (네이버 금융 RSS / API)
         │        ├─► 정량 데이터 + 뉴스 → Gemini Flash API
         │        └─► ai_insights 테이블 저장 (rate limit: 4초 간격)
         ├─► R2 업로드: latest.db + history/YYYY-MM-DD.db
         ├─► 7일 이상 백업 삭제
         └─► latest_metadata.json 갱신

[사용자 대시보드 접속]
         │
         ├─► 캐시 확인 (30분 TTL)
         ├─► 만료 시: R2에서 latest.db 다운로드
         └─► SQLite 쿼리 → UI 렌더링 (AI 가이드 포함)
```

| Streamlit Cloud 콜드 스타트 지연 | 중        | 낮음   | 적극적 캐싱 + 스피너 UX                           |
| 재무 데이터 품질 (오래된 공시)   | 중        | 중     | 신선도 체크 + UI 경고 표시                        |

## 16. V2: AI 정성 분석 파이프라인

> **설계 배경**: 정량 지표(재무 스코어)는 기업의 과거 성적표다. 시장 트렌드·뉴스·거시경제 동향이라는 '미래의 방향타'를 결합하면 투자 판단의 정확도가 높아진다. Gemini Free Tier를 활용하여 추가 비용 없이 LLM 기반 정성 분석을 제공한다.

### 16.1 AI 분석 범위 (Stage 5)

Stage 4 랭킹 완료 후, **상위 N개 종목**에 한해 AI 정성 분석을 수행한다.

| 분석 차원        | 내용                                             | 데이터 소스                    |
| ---------------- | ------------------------------------------------ | ------------------------------ |
| 뉴스 감성 분석   | 최근 1개월 헤드라인 긍정/부정/중립 분류          | 네이버 금융 뉴스 RSS           |
| 업황·테마 동향   | 해당 섹터의 시장 자금 흐름 및 순환매 위치        | Gemini 추론 (학습 데이터 기반) |
| 매크로 상관관계  | 환율·유가·금리 민감도, 수출 비중 여부            | 정량 데이터 + Gemini 추론      |
| 종합 투자 가이드 | [현황 / 최근 이슈 / 시장 분위기 / 결론] 4단 요약 | Gemini 생성                    |

**분석 대상 기본값**: Stage 4 상위 30개 종목 (설정 파일로 조정 가능)

### 16.2 AI 가이드 출력 형식

```
[ValueForge AI 가이드 — {종목명} ({종목코드})]
```

### 16.4 기술 설계

#### 파일 구조

```
src/
├── collectors/
│   ├── news_collector.py       # 네이버 금융 뉴스 RSS 수집기
│   └── gemini_client.py        # Gemini API 래퍼 (rate limit, retry 포함)
├── screening/
│   └── stage5_ai_analysis.py   # Stage 5 오케스트레이터
└── db/
    └── repository.py           # upsert_ai_insights() 메서드 추가
```

#### 프롬프트 설계 원칙

- **시스템 프롬프트**: 역할 정의 (한국 주식 분석 AI), 출력 형식 고정, 투자 권고 금지 고지
- **사용자 프롬프트 구성**:

  ```
  [정량 데이터]
  종목명: {name}, 시장: {market}, 섹터: {sector}
  종합점수: {score}/100, 가치:{v} 품질:{q} 안전성:{s} 성장:{g} 모멘텀:{m}
  PER: {per}, PBR: {pbr}, ROE: {roe}%, 부채비율: {debt_ratio}%

  [최근 뉴스 헤드라인]
  1. {headline_1}
  2. {headline_2}
  ...

  위 데이터를 바탕으로 투자 가이드를 작성해 주세요.
  ```

- **토큰 추정**: 입력 ~1,500~2,500 토큰 + 출력 ~300~500 토큰 = 종목당 ~2,000~3,000 토큰

#### DB 스키마 추가 (`ai_insights` 테이블)

```sql
CREATE TABLE IF NOT EXISTS ai_insights (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    ticker        TEXT    NOT NULL,
    run_date      TEXT    NOT NULL,  -- YYYY-MM-DD
    guide_text    TEXT    NOT NULL,  -- AI 생성 전문
    sentiment     TEXT,              -- positive / negative / neutral
    generated_at  TEXT    NOT NULL,  -- ISO 8601
    model_used    TEXT    NOT NULL,  -- e.g. gemini-1.5-flash
    UNIQUE(ticker, run_date)
);
```
